# FlowSound

A focus app with a built-in song player.

FlowSound is a simple focus app made to help you stay focused while studying. It has a built-in song player with chill lofi tracks to help you get in the flow.

## Features

- Focus app with a built-in song player
- Simple and easy to use
- Chill songs to help with concentration

## Tech Stack

- **Frontend**: flowsound-frontend (Next.js)
- **Backend**: flowsound-backend (FastAPI)

## Getting Started

### Prerequisites

- Node.js (for frontend)
- Python 3.x (for backend)

### Running the App

- Start: `./start.sh`
- Stop: `./stop.sh`
